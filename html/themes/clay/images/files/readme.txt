Icons in this theme
===================

The icons are Material Icons by Google (https://fonts.google.com/icons),
taken from the npm package @material-design-icons/svg 0.14.13, recoloured
with this theme's palette and rendered to PNG at the sizes TorrentFlux uses
(they keep the old .gif / .png file names the PHP code expects).

Material Icons are licensed under the Apache License, Version 2.0:
https://www.apache.org/licenses/LICENSE-2.0

The build scripts are in docs/theme-tools/ of the TorrentFlux NX source.
